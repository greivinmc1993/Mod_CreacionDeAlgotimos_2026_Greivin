Configuración:

Windows
Config. VariablesEntorno_Windows: Variables de entorno: Path/editar/nueva y agregar la ruta: c:\MinGW\bin

VS Code
En VS Code: Descargar las extensiones: C/C++ de Microsoft v1.21.6  y C/C++ Code Runner v011.3 Jun Han

Para poder correr los programas en la terminal

Configuración - Settings - Open Settings (JSON). Arriba-Derecha:

"code-runner.runInTerminal": true,

"code-runner.saveFileBeforeRun": true
